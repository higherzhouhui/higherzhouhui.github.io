# 日记模块使用说明

## 📖 功能概述

本博客新增了一个加密的日记模块，用于记录每天的重要事项和逐步建立用户画像。日记数据采用 AES-GCM 加密算法保护，即使仓库公开，未经密码验证也无法读取日记内容。

## 🔐 安全特性

- **加密存储**：所有日记内容和图片使用 PBKDF2 + AES-GCM 加密
- **密码验证**：需要输入密码才能查看日记
- **有效期管理**：密码验证后10天内有效（存储在 localStorage）
- **无明文泄露**：仓库中不存在明文密码或日记内容

## 📂 数据结构

```
/diary
├── index.json          # 日记索引（包含日期列表和密码验证数据）
├── data/               # 加密的日记数据
│   └── 2026-10-13.json
└── images/             # 加密的图片
    └── [加密图片文件]
```

### 日记数据格式（解密后）

每个日记文件包含以下字段：

```json
{
  "date": "2026-10-13",
  "userProfile": "用户画像描述（每天更新，逐步完善）",
  "events": "今天的重要事项（只记录重要的，不是流水账）",
  "images": ["图片文件名列表"]
}
```

## 🚀 如何新增日记

### 方法一：使用自动化脚本（推荐）

运行以下命令启动交互式脚本：

```bash
node scripts/add-diary.js
```

脚本会引导你完成以下步骤：

1. **输入密码**（默认：wind9527）
2. **输入日期**（默认：今天）
3. **输入用户画像**（多行输入，输入 END 结束）
4. **输入重要事项**（多行输入，输入 END 结束）
5. **输入图片路径**（可选，多个用逗号分隔）

脚本会自动：
- 加密日记内容和图片
- 保存到对应目录
- 更新索引文件

### 方法二：手动创建

1. 准备日记数据（JSON 格式）
2. 使用加密工具加密内容
3. 保存到 `/diary/data/YYYY-MM-DD.json`
4. 更新 `/diary/index.json` 索引

## 🔧 配置说明

### 修改默认密码

默认密码为 `wind9527`，如需修改：

1. 更新 `/diary/index.json` 中的 `passwordTest` 字段（使用新密码加密）
2. 重新加密所有现有日记

### 修改有效期

在 `/src/utils/auth.js` 中修改 `VALID_DAYS` 常量：

```javascript
const VALID_DAYS = 10; // 修改为你想要的天数
```

## 🎨 页面访问

- **日记入口**：首页导航栏 → 日记
- **直接访问**：`/diary`
- **密码验证**：首次访问需要输入密码
- **自动登录**：10天内无需重复输入密码

## 🛠️ 技术实现

- **加密算法**：PBKDF2 (100,000 iterations) + AES-GCM-256
- **前端框架**：React + React Router
- **样式设计**：响应式布局，时间线风格
- **状态管理**：localStorage（认证状态）

## 📌 注意事项

1. **密码保护**：请妥善保管密码，忘记密码将无法恢复日记内容
2. **数据备份**：建议定期备份 `/diary` 目录
3. **图片大小**：加密会增加文件大小（约 +33%），建议压缩图片后上传
4. **浏览器兼容**：需要支持 Web Crypto API 的现代浏览器
